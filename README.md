# 🛒 Amazon Frontend Clone

A responsive **Amazon-inspired e-commerce frontend clone** built using HTML, CSS, and JavaScript. This project replicates the look and feel of Amazon's homepage and helps in understanding modern frontend development concepts.

## 📌 Features

* Responsive design (Mobile + Tablet + Desktop)
* Amazon-style navigation bar
* Product listing section
* Hero/banner section
* Footer similar to Amazon
* Hover effects and UI interactions

## ⚙️ How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/your-username/amazon-clone.git
```

2. Navigate to the project folder

```bash
cd amazon-clone
```

3. Open `index.html` in your browser
